# gotsum-feed

GOTSUM(하루정산) 앱의 "근처 행사 추천"에 쓰는 공개 행사 피드입니다.

- 매일 한국시간 03:00, GitHub Actions 가 공공데이터를 받아 시·도별 JSON 으로 만들어 GitHub Pages 에 올립니다.
- 앱은 사용자가 고른 시·도 파일(`v1/{코드}.json`) 하나만 내려받고, 추천은 기기 안에서 합니다.
- 개인정보는 다루지 않습니다.

## 데이터 출처
- 서울특별시 문화행사 정보 — 서울 열린데이터광장 / 서울문화포털 (공공누리 제1유형: 출처표시)

원본 코드는 GOTSUM 앱 저장소의 `events-feed/`, `src/domain/events.ts` 에서 관리합니다.
